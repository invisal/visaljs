# Contributing

visaljs is early, and its design still changes often. For now it doesn't accept pull requests:
a pull request from outside the project is closed without review. This will change when the
project is ready for it.

What helps now:

- **Bug reports.** A program that visaljs compiles wrongly, or that runs differently from Node.
  Open an issue with the smallest program that shows it, what Node prints, what the compiled
  program prints, and the output of `visaljs --version`.
- **Programs and packages that don't compile.** Name the package and its version, or include
  the code, and the error visaljs gives.
- **Questions and feedback**, in an issue.

Security vulnerabilities are not reported in issues: see [`SECURITY.md`](SECURITY.md).
